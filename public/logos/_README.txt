Drop your client logos in this folder.

- Formats: PNG, SVG, JPG, WEBP or AVIF.
- Best results: transparent background, dark or single-color logo, about 300px wide or more.
- The carousel on the home page picks up every image here, in alphabetical order.
  Name files in the order you want, for example 1-veltra.svg, 2-orsini.png ...
- The file name becomes the alt text, so "orsini-group.png" reads as "orsini group".
- Aim for about 6 logos. Restart "npm run dev" if a new file does not show up.
